# Notes

Your requests about moves, Abilities, items and TMs, written in `PokeSquad Battler Reference.html`.

1. In the Reference, tap **+ Note** on any move, Ability, item or TM and write what you'd like changed. Notes stay in that browser
   until you export them.
2. Tap **Notes** (top right), then **Export new notes**. Chrome and Edge write the file straight into this folder (choose this
   `Notes` folder the first time). Other browsers download it: move the file in here.
3. Ask Claude to review the notes. For each note Claude makes the change (or says why not), adds a **Done:** or **Not done:** line
   under it, and moves the file to `done/`.
4. After the next rebuild of the Reference, each handled note shows **✓ Done** with Claude's reply. **Remove done notes** in the Notes
   list clears them.

Files here: `notes YYYY-MM-DD HHMM.md`, one per export, a section per note. Each section keeps a hidden line like
`<!-- note: move:thunderbolt @1760000000000 -->` (which note, and which version of it) so the reply finds its way back.
